# Emotion Palette

A gentle way to find the words for how you feel.

## GitHub Pages

This site deploys automatically from `main` using the official GitHub Pages build-and-deploy actions. The workflow packages the repository root directly, so there is no `dist/` directory to maintain.

In the repository settings, open **Pages** and set **Source** to **GitHub Actions**. After the workflow completes, the site will be available at:

`https://mohnjahoney.github.io/emotion-palette/`
